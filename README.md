# Grocery List App
https://clever-clafoutis-9e32d5.netlify.app/
## Overview
This is a Grocery List App built using **React + Vite**.  
The app allows users to add, view, edit, and delete grocery items.

## Features
- Add new grocery items
- Display items using ui
- Edit items
- Delete items
- Simple and clean UI
- Simple stats display (item count)
- Digits / Alphabet Counter 

## Technologies Used
- React
- Vite
- JavaScript
- CSS

## How to Run
1. Install dependencies:
   ```bash
   npm install
2. Run the project
   ```bash
   npm run dev
